# ML Experiment Tracking with MLflow

## Description
This project demonstrates how to use MLflow to track and compare machine learning experiments. We trained an XGBoost regression model on the California Housing dataset to predict median house prices. The goal of the project was to train the model using three different hyperparameter configurations, track the metrics using MLflow, and identify the best-performing model.
